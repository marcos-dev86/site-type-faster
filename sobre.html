Como o Type Faster foi feito

Um projeto de escola com app mobile, API serverless, banco de dados e tempo real — cada peça com seu próprio papel.

arquitetura

As três pontas do sistema

O app nunca fala direto com o banco. Toda regra do jogo passa pela API; o banco só guarda dado, e o Ably só avisa os celulares quando algo muda.

stack técnico

Peça por peça

React Native + Expo

O app que roda no celular: telas de sala, digitação e perfil, navegação com expo-router e um UUID por aparelho salvo com AsyncStorage pra identificar o jogador.

Vercel (API)

Funções serverless em TypeScript — uma rota por arquivo — que criam salas, sorteiam palavras, validam progresso e fecham a partida. É a única parte do sistema com acesso ao banco.

Neon (Postgres)

Guarda salas, jogadores dentro de cada sala, perfis (XP, nível, vitórias) e o histórico de partidas encerradas.

Ably

Canal em tempo real por sala. Avisa quando o adversário entra, quando a partida começa, o placar dele mudando ao vivo e o resultado final — tudo sem o celular precisar ficar perguntando pro servidor.
